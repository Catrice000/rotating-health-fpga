## 已完成

- 综合、布局、布线与比特流生成成功。
- 最终内部处理时钟 50 MHz：setup WNS **+1.828 ns**，hold WHS **+0.035 ns**；TNS、THS 均为 0。
- 使用 LUT 3395 / 20800，寄存器 4779 / 41600，BRAM 2.5 / 50，DSP 16 / 90。
- 默认 DRC 没有 Error。仍有 DSP 流水线建议及 CFGBVS / CONFIG_VOLTAGE 未声明的 Warning；没有降低任何 DRC 错误等级。配置电压属性和外部接口电气时序尚未由完整板级原理图/示波器复核。
- FFT：单音、冲激、随机三组向量通过；相对 NumPy Hann FFT/N，实部/虚部复误差最大约 4.93 个 Q6 单位，即归一化 FFT 输出不足 0.078 ADC count。
- AMD XPM 官方块 RAM 仿真模型的 FFT 输出与参考同步 RAM 模型逐位一致。
- I²C：设备 ID 寄存器读、配置写及无 ACK 检测通过。
- FPGA 特征：固定输入能量/峰值打包、基线完成、正常和能量异常规则通过。
- 编码器：4096 计数一圈、反转、非法双位跳变通过。
- 电机控制：无命令不启动、运行中换向拒绝、超范围转速拒绝、运行中调速及周期渐变、停止优先、S4 按住禁止启动、远程心跳超时停车通过。
- UART：真实 RTL 串行波形解码后，样本/特征帧与 Python CRC 解码结果完全匹配。
- Python：CRC 标准向量、逐字节输入、损坏帧恢复、特征布局、未标定不判健康等六项检查通过。
- 上位机：窗口启动，以及正常/不平衡疑似/松动疑似/转速异常四类合成演示流程通过。

## 验证边界

没有下载本次新增控制版本到用户实物板卡，没有启动实际电机，没有采集真实正常/故障样本。
因此“可运行”指已完成构建、逻辑/协议/数值检查和本机界面启动；实物传感器、接线、电源噪声与机械诊断准确率仍待现场验收。
仿真中的故障注入验证的是规则响应，不代表真实故障识别灵敏度或误报率。
内部时序通过不等于所有外部接口电气时序已完成验证。

## 推荐现场验收顺序

1. D36A 断电，下载位流；确认串口心跳、DEVID=E5、三轴原始数据和编码器计数。
2. 手动缓慢转动编码器整圈，确认 4096 或 4000；不一致时修改参数并重建，不用错误 PPR 标定。
3. 电机安全空载、固定安装，S0 启动，确认方向和实际 RPM；S4 必须能停止。
4. 保持正常状态和固定转速，S1 标定；正常记录不得持续触发振动异常。
5. 先做可恢复、受控的轻微激励验证，不制造危险松动或不受控偏心负载；记录相同工况下的正常/异常数据。
6. 用独立转速表/示波器核对采样、转速、信号完整性，再讨论定量精度和故障识别率。
